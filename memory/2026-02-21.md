## Key files
- `router/config.py` — model tiers, key loading
- `agents/strategy_consultant/orchestrator.py` — main engagement loop
- `agents/strategy_consultant/cost_estimator.py` — cost+time gate (required before any run)
- `agents/strategy_consultant/status_reporter.py` — 5-min Telegram updates during runs
- `AGENTIC_ECOSYSTEM.md` — full vision + future roadmap
- `engagements/` — one folder per engagement, persists forever

## Decisions / preferences
- Always show cost+time estimate before engagement, require approval
- 5-min Telegram status updates during long runs
- PDF output preferred; Telegram delivery
- Proactivity = H/M/L per engagement
- Router: Haiku for simple/cheap, Opus only where judgment matters
